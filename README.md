## Illyrian Care Hospital Website

## Overview
The Illyrian Care Hospital Website is a simple, clean, and easy-to-use website that helps patients, visitors, and staff find important hospital information. 
It includes pages for services, departments, doctors, milestones and contact details. The website is fully responsive, so it works well on phones, tablets, and computers.

## Tools
HTML, CSS, JavaScript, SQL 

## Features
- Fully responsive layout
- Navigation bar and multi-page structure
- Appointment, contact form, login/sign up profile
- Clean and modern UI designed for healthcare
  
## How to Run the Project
- Download the files. 
- Make sure you have Node.js installed.
- Open the terminal and navigate to the project folder.
- Run the server using: node server.js and node account.js for login/signup page.
- Make sure your MySQL server is running and the database is set up correctly.
- Open the project folder.
- Launch index.html in any browser.
